# ÜY — жылжымайтын мүлік платформасы

Бұл жоба — ÜY сайтының жұмыс істейтін Full-Stack MVP қаңқасы: responsive frontend, Express backend, SQLite деректер базасы, сессия арқылы авторизация, хабарландыруларды іздеу/сүзу, таңдаулылар және хабарландыру жариялау.

## Технологиялар
- HTML5, CSS Grid/Flexbox, vanilla JavaScript
- Node.js + Express
- SQLite (`better-sqlite3`)
- bcrypt құпиясөз хэштеу, `express-session`
- Helmet базалық HTTP қауіпсіздік тақырыптары

## Іске қосу
1. Node.js 18+ орнатыңыз.
2. Терминалда осы бумаға кіріңіз.
3. `npm install`
4. `.env.example` файлын `.env` деп көшіріп, `SESSION_SECRET` мәнін ауыстырыңыз.
5. `npm start`
6. Браузерде `http://localhost:3000` ашыңыз.

Деректер базасы бірінші іске қосылғанда автоматты түрде `data/uy.sqlite` файлына жасалады және үлгілік хабарландырулармен толтырылады.

## Қазір жұмыс істейтін мүмкіндіктер
- Үй хабарландыруларын қарау, іздеу және сүзу
- Сатып алу / жалға алу түрін таңдау
- Таңдаулыларды аккаунтпен байланыстыру
- Тіркелу және жүйеге кіру
- Жаңа хабарландыру жариялау (жүйеге кірген пайдаланушы үшін)
- Аудан туралы бастапқы ақпараттық блок
- Адаптивті мобильді навигация

## Маңызды шектеулер
- Бұл — MVP, өндірістік іске қосылым емес.
- Картаға әзірге статикалық көрнекі блок берілген; нақты карта үшін Mapbox/2GIS/Google Maps кілті және дерек көзі қажет.
- Аудан қауіпсіздігіне қатысты нақты рейтинг ойдан шығарылмайды. Көрсетілген мәтін ақпараттық сипатта; нақты дереккөз интеграцияланғанша оны ресми статистикамен толықтыру керек.
- Фотолар демо ретінде сыртқы URL-дерден алынады. Өндірісте суреттерді серверге/объектілік қоймаға жүктеу және модерация қажет.
- Өндірісте HTTPS, тұрақты session store, CSRF қорғанысы, rate limiting, валидация, журналдау және құпия деректер саясаты қосылуы керек.
- Үлгілік пайдаланушы деректері мен қаржылық/жеке деректер PDF-тен көшірілмеді; қауіпсіздік үшін демонстрациялық деректер қолданылады.

## API
- `GET /api/listings?type=rent&city=Ақтау&query=...`
- `GET /api/listings/:id`
- `GET /api/me`
- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/favorites`
- `POST /api/favorites/:listingId`
- `DELETE /api/favorites/:listingId`
- `POST /api/listings`
